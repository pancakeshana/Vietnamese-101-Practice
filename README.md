## Vietnamese 101 Practice Website
This is a website created to practice typing or writing Vietnamese, including accents. 
The content is based on SDCCD Mesa College's VIET 101 course by Professor Ngoc Luong Nguyen.

Accents are difficult to remember when English-speakers are more used to memorizing the 
alphabetical letters when introducing new vocabulary. By grinding "problems" and translating words/sentences
from English to Vietnamese.

This is a student project out of trying times and NEVER malicious intent.

VSCode's copilot AI contributed to the making of script.js.
